# V5 — التشغيل المحلي

1. ثبّت Python 3 على Windows.
2. شغّل start-v5.bat.
3. افتح http://127.0.0.1:8765
4. ارفع صورة واكتب طلب التعديل.
5. لفحص العتاد: شغّل tools/check-hardware.ps1.

مهم: التطبيق لا يتجاوز أنظمة أمان النماذج أو مزودي الخدمة. الهدف هو تحرير الصور العادي بأقل قيود غير ضرورية، مع الالتزام بمتطلبات السلامة.
