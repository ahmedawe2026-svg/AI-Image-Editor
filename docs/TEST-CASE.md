# الاختبار الأساسي

الصورة: صورة شخصية عادية.

الطلب:
"أضف شريكًا يجلس بجانبها بكل حب وود، مع الحفاظ على ملامحها وإضاءة الصورة وتناسق المشهد."

معايير النجاح:
1. عدم تغيير ملامح الشخص الأصلي دون طلب.
2. إضافة الشخص الجديد في الموضع المناسب.
3. مطابقة الإضاءة والمنظور والحجم.
4. الحفاظ على الخلفية قدر الإمكان.
5. إظهار النتيجة داخل المحرر.
