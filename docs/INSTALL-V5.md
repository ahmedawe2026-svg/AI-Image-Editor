# تثبيت V5 على Windows

## 1) Python
ثبّت Python 3 إذا لم يكن موجودًا.

## 2) فحص الجهاز
شغّل:
`tools\check-hardware.bat`

النتيجة المطلوبة: حجم RAM، اسم بطاقة الرسوميات، وذاكرة البطاقة إن كانت ظاهرة.

## 3) ComfyUI
لا تثبت نموذجًا عشوائيًا الآن. ComfyUI متاح رسميًا على Windows، ويدعم التشغيل المحلي وواجهة API، كما أن التوافق والأداء يختلفان حسب نوع GPU. citeturn0search0turn0search2

## 4) محرر الصور
شغّل `start-v5.bat` ثم افتح:
http://127.0.0.1:8765

بعد معرفة GPU/VRAM سنضيف Workflow فعليًا للتعديل التوليدي.
